# ATS Research — Experiment Scripts

Reproducibility code for:
**"Personalising STEM Learning at Scale: An Adaptive AI Tutoring Suite
with Student Modeling, Curriculum Sequencing, and Explainable Formative Feedback"**
*Education Sciences, MDPI (submitted 2026)*

---

## Requirements

```bash
pip install pandas numpy scikit-learn sentence-transformers rouge-score sympy matplotlib
```

## Usage

Run scripts in order:

```bash
# 1. Preprocess ASSISTments dataset (download from assistments.org first)
python preprocess_assistments.py --input skill_builder_data_corrected.csv

# 2. Generate synthetic cohorts
python synthetic_generator.py

# 3. Evaluate student models → Table 3
python eval_student_models.py

# 4. Evaluate sequencing policies → Table 4
python eval_sequencing.py

# 5. Evaluate feedback pipeline → Table 5 (automated metrics)
python eval_feedback.py

# 6. Rate hints (open data/feedback/hint_samples_50.csv, fill rule/llm/hybrid/gold columns 1-5)
python eval_feedback.py --with-ratings data/feedback/hint_samples_50.csv

# 7. Generate calibration figure → Figure 4
python plot_calibration.py
```

## Data

- **ASSISTments 2009–10**: https://sites.google.com/site/assistmentsdata/
- **EdNet KT1**: https://github.com/riiid/ednet
- Synthetic cohorts are generated by `synthetic_generator.py` (seed=42, fully reproducible)
